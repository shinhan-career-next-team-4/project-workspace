# 미결 질문

spec-verifier, finance-domain-reviewer, tech-architect가 질문을 추가한다. 팀이 결정하면 decisions.md에 기록하고 상태를 "결정됨 → D-번호"로 바꾼다.

## 질문 형식
```
### Q-번호: [한 줄 질문]
- 관련: FR-xxx
- 심각도: 개발 차단 / 개발 중 혼란 / 사소함
- 왜 문제인가:
- 선택지: A) ... / B) ...
- 상태: 미결
```

---

### Q-001: 3구간(상위 10% / 하위 10%) 산정의 최종 방식은?
- 관련: D-006
- 심각도: 개발 중 혼란
- 왜 문제인가: 지금은 임시값이라, 계산 API와 화면 문구가 나중에 바뀔 수 있다.
- 선택지: A) 임시값으로 해커톤 진행, 방식은 고도화 단계에서 결정 / B) 1주차 안에 확정
- 상태: 미결
