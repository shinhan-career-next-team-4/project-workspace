# GOAL-AGENT-SRS: 목표 기반 개인 자산관리 AI Agent 요구사항정의서

> 3주 해커톤 MVP 범위. 기획 에이전트들은 이 파일을 기준으로 작업합니다.

## 읽는 법
- **ID 체계**: `CP`(공통 원칙), `FR-<영역>`(기능), `NFR-<영역>`(비기능). 영역: AI, ALT(대안), AUTH, CMP(비교), DATA, INP(입력), PLAN(내 계획), RES(결과)
- **우선순위**: Must / Should / Could
- **상태**: 확정 / 부분확정 (부분확정은 `출처`의 TBD·CF 항목이 남아 있다는 뜻)
- **출처**: `TBD-xx`, `CF-xx`는 Notion에서 관리하던 미결·결정 항목 번호입니다. 원문은 `docs/notion-decisions.md`에 있습니다. `D-xxx`는 이 repo에서 기록한 결정(docs/decisions.md), `Q-xxx`는 이 repo의 질문(docs/open-questions.md)입니다.

## 수용 기준

### FR-PLAN-05 내 계획 유지(시작월 고정)
- 정상: Given 3월에 내 계획을 저장하고 로그아웃한 사용자 / When 5월에 다시 로그인하면 / Then 내 계획의 조건과 시작월(3월)이 저장한 그대로 유지되고, 최신 금리·지수 데이터로 다시 계산하지 않는다.
- 예외: Given 저장 이후 기준 데이터(금리, 지수)가 갱신된 상태 / When 다시 로그인하면 / Then 갱신된 데이터가 내 계획의 계산에 반영되지 않는다.
- 예외: Given 저장된 내 계획이 없는 계정 / When 로그인하면 / Then 시작월을 만들지 않고 빈 입력 화면으로 이동한다(FR-PLAN-06).
- 정상(D-013): Given 3월 시작월로 저장된 내 계획을 5월에 다시 연 사용자 / When 입력 수정에서 값을 바꿔 결과 보기를 누르거나, 대안 적용·대화 적용·되돌리기를 하면 / Then 어느 경우든 시작월은 3월 그대로다.
- 예외(D-013): Given 위와 같은 사용자 / When 요청이 5월에 들어와도 / Then 요청일(5월)로 시작월을 다시 정하지 않는다.

### FR-PLAN-01 적용 요청과 확인
- 정상: Given 대안 카드의 '내 계획으로 적용'을 누른 사용자 / When 확인창이 뜨면 / Then 바뀌는 내용이 보이고, '적용하기'를 누르기 전까지 내 계획은 바뀌지 않는다.
- 예외(D-016): Given AI 대화로 바꾼 조건의 비교 결과가 대화창에 있는 사용자 / When 내 계획으로 적용하면 / Then 확인창 없이 적용 절차가 진행된다.

### FR-AI-07 대화 재계산 결과 표시
- 정상: Given 사용자가 대화로 조건 하나를 바꾼 상태 / When 재계산이 끝나면 / Then 대화창에 현재 조건과 바꾼 조건의 비교 결과가 보이고, 이 시점에는 내 계획이 바뀌지 않는다.
- 정상(D-016, D-013): Given 위 비교 결과 / When 사용자가 내 계획으로 적용하면 / Then 확인창 없이 내 계획에 반영되고 저장된 시작월은 그대로다.
- 예외: Given 대화로 받은 값이 CP-02 허용 범위를 벗어난 경우 / When 적용하려 하면 / Then [미결: Q-021] 동작이 정해지기 전까지는 구현하지 않는다(확인창이 없어서 범위 밖 값이 바로 계획에 들어갈 수 있음).

### FR-INP-04 목표 기간 입력
- 정상: Given 월 저축 가능 금액을 아는 사용자 / When 목표 기간을 정하지 않고 결과 보기를 누르면 / Then 검증을 통과하고 결과 화면이 목표 금액까지 걸리는 시간을 보여준다(D-005, D-008).
- 정상(D-015): Given 월 저축 가능 금액을 '잘 모르겠어요'로 답한 사용자 / When 목표 기간(예: 3년 0개월)과 목표 금액을 입력하면 / Then 결과 화면에 필요 월 저축액이 표시된다(FR-RES-08).
- 예외(D-015): Given 월 저축 가능 금액을 '잘 모르겠어요'로 답했는데 목표 기간이 비어 있는 사용자 / When 결과 보기를 누르면 / Then 필요 월 저축액을 계산할 수 없으므로 목표 기간 입력을 요구하고 결과 화면으로 넘어가지 않는다. 안내 문구와 화면 흐름은 [미결: Q-027].
